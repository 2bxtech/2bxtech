## Selected projects

### [FitLife Personalization Engine](https://github.com/2bxtech/fitlife-personalization-engine)

An event-driven full-stack personalization case study built with **.NET 8, Vue/TypeScript, SQL Server, Redis, and Kafka**.

Explores transactional consistency, event ingestion, concurrency and idempotency, caching, authorization boundaries, and reliability.

### [AI Service Debugger](https://github.com/2bxtech/ai-service-debugger)

A developer tool built with **React/TypeScript, Node.js, and the Claude API** for investigating microservice failures.

Parses logs, visualizes service relationships and failure cascades, and generates structured root-cause hypotheses for further investigation.

### [Content Repurpose Platform](https://github.com/2bxtech/content-repurpose-platform)

A multi-tenant AI content platform built with **Python/FastAPI, PostgreSQL, Celery, Redis, React, and TypeScript**.

Includes row-level security, asynchronous processing, WebSocket updates, authentication controls, AI provider failover, and distributed tracing.

### [Financial Dashboard](https://github.com/2bxtech/financial-dashboard)

An interactive financial data dashboard built with **React and TypeScript**, supporting CSV/Excel imports, data visualization, and multiple export formats.
